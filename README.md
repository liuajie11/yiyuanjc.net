# 一元机场收录

一个无需构建工具的静态中文内容站原型，采用顶部全局导航、左侧栏目目录、中间正文、右侧文章大纲的三栏知识库布局。

## 本地预览

直接打开 `index.html`，或在目录中启动任意静态文件服务器。例如：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 页面栏目

- 首页
- 机场推荐
- 深度测评
- 客户端教程
- AI 工具
- 故障与专线技术
- 关于我们

内容数据与页面路由集中在 `app.js` 的 `pages` 对象中，后续可以直接替换为真实文章或接入 CMS。
